# Piglin Free Portals

This repository contains two maintained version lines of `Piglin Free Portals`.

- `1.21.11/` is the legacy line for Minecraft `1.21.11`.
- `26.1.2/` is the current line for Minecraft `26.1.2`.

The mod prevents piglins from spawning from Nether portals, keeping portal areas cleaner and reducing wasted mobcap pressure.

## Downloads

Release assets are published with clear Minecraft version names:

- `piglin-free-portals-<version>-mc1.21.11.jar`
- `piglin-free-portals-<version>-mc26.1.2.jar`

## Development

Each version folder builds on its own. Keep version-specific code inside its own folder because mappings, Java targets, and Fabric APIs differ between the two lines.
